# Applied Energistics 2 NH

## About

>A Mod about Matter, Energy and using them to conquer the world..

This project is a GTNH fork of Applied Energistics 2 for Minecraft 1.7.10

> [!NOTE]
> AE2NH is not API-compatible with the original Applied Energistics 2. If you need to use older addons, please use [Applied-Energistics-2-Unofficial](https://github.com/GTNewHorizons/Applied-Energistics-2-Unofficial) instead.

> [!WARNING]
> AE2NH is currently undergoing a major rewrite, so its API is unstable and may change without notice.
